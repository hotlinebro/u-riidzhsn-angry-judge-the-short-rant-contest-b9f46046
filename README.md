Write one short, funny rant about an everyday annoyance and let a furious judge decide which one lands hardest. This entry rants at a printer that ate 23 print jobs, delivered $0 worth of paper, and still charged for the ink it swallowed overnight. A judge model compares the rants in pairs and the funniest takes one of three paid places.

## Run it

```sh
node main.ts
```

This writes a single rant (134 characters) to `/output/entry.txt`.
